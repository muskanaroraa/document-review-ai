# AI Document Review System

AI-powered system that analyzes documents and generates structured insights.

## Problem

Reviewing long documents such as PRDs, API specifications, contracts, and technical documentation takes time. Important issues can easily be missed.

Existing AI tools require manual prompting and do not automatically analyze documents in a structured way.

## Solution

This project builds an AI-powered system that automatically reviews uploaded documents and generates:

- summaries
- potential risks
- action items
- structured insights
- questions to investigate

## Core Features (Planned)

- Document upload (PDF, DOCX, TXT)
- Document parsing
- AI-powered analysis
- Risk detection
- Structured summaries
- Chat with document
